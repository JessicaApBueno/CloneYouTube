# Clone da Interface do YouTube

 
Este é um projeto de estudo para recriar a interface de uma página de visualização de vídeo do YouTube usando HTML e o framework de CSS, Tailwind CSS. O objetivo é praticar a criação de layouts responsivos, componentes reutilizáveis e a estruturação de uma página web.

## Funcionalidades Recriadas
Cabeçalho (Navbar): Com logo, barra de pesquisa e ícones de usuário.

Seção Principal: Contendo o player de vídeo e os detalhes do vídeo (título, canal, número de inscritos, botões de ação e descrição).

Barra Lateral: Com a lista de vídeos sugeridos para simular o comportamento da plataforma.

## Estilização e Responsividade: 
O projeto é estilizado para se parecer com o tema escuro do YouTube e é totalmente responsivo, adaptando-se a diferentes tamanhos de tela (desktop, tablet e mobile).

## Como Executar o Projeto
Não é necessário nenhum ambiente de desenvolvimento local complexo para visualizar este projeto. Por ser um arquivo HTML simples com um link para o CDN do Tailwind CSS, você pode simplesmente abrir o arquivo index.html em qualquer navegador web.

## Estrutura do Código
O código-fonte está contido em um único arquivo index.html para simplificar o projeto de estudo. As classes do Tailwind CSS são aplicadas diretamente nos elementos HTML.
